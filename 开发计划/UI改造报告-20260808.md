# UI 改造开发报告

日期：2026-08-08

## 需求

1. 去掉面板最上方的两个按钮：`桶子工具箱`（跳转网页提示）和 `卡死反馈`（反馈提示）。
2. 改善 `Ease` 与 `AnchorMove` 的交互体验：原先用 Slider 很难精确命中目标值（如 `1`、`50`、`90`）。
3. 精简 `motion2` 功能区：只保留 `Nul` 和 `Vig`，其余删除，并合并进 `keyfast` 行。
4. 在 `commit` 前把本次开发报告写进 `开发计划/`。

## 方案尝试与试错

### Ease / AnchorMove 交互

**第一次方案：Slider + 数字输入框**
- 思路：保留 Slider 直觉，旁边加 `EditText` 输入精确值。
- 未采用原因：用户临时选择了更快捷的「预设按钮」方案 B。

**第二次方案：预设按钮 + 数字输入框（方案 B）**
- Ease：每行放 `0 / 50 / 90 / 100` 快捷按钮 + 输入框。
- AnchorMove：左侧 `3×3` 九宫格（`┌┬┐ / ├┼┤ / └┴┘`）快速定位，右侧 `x / y` 输入框 + Reset。
- 问题：
  - Ease 预设按钮虽然快，但连续微调不如滑轨顺手。
  - `0` 和 `100` 是极端值，用户担心会触发不期望的 ease 行为。

**最终方案：Slider + 数字输入框，并钳制到 1~99**
- Ease 三行改回 `Slider + EditText`。
- Slider 资源直接写死 `minvalue:1, maxvalue:99, value:50`。
- 数字框输入时统一用 `clampEase` 钳制到 `1~99`，滑块拖动时也同步更新数字框。
- AnchorMove 保持九宫格 + `x/y` 输入框不变。

### motion2 精简

- 删除按钮：`Buc`、`Bld`、`Bst`、`Rop`、`Wap`、`Str`。
- 保留：`Nul`、`Vig`。
- 把这两个按钮合并进原来的 `keyfast` 行，标签改为更宽泛的 `tools`。
- handler 路径从 `line2` 改到 `line1`。

## 实现摘要

修改文件：`src/ui.jsx`
- 删除顶部 `title` 分组及两个按钮的 `onClick`。
- `line1` 改成 `tools` 行，加入 `Nul`、`Vig`。
- 删除 `line2` 整行。
- `lineA`（Ease）改为三行 Slider + EditText，带 `1~99` 钳制。
- `lineB`（AnchorMove）改为九宫格 + `x/y` 输入框 + Reset。
- 重写 Ease 与 AnchorMove 的 handler 绑定逻辑。

构建：`bash ./build.sh` 成功生成 `visnlink.jsx`。
