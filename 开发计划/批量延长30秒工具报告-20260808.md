# 批量延长 30 秒工具开发报告

日期：2026-08-08

## 需求

仿照 `MB`（批量开启 Motion Blur）的递归思路，新增一个批量工具：把当前活跃合成及其所有嵌套合成的**时长**和**所有图层 outPoint** 都增加 30 秒。

主要场景：导入 PSD 后，Photoshop 的图层/组会被拆成多个合成和图层，默认时长通常只有 10 秒。如果要做 1 分钟动画，需要逐个合成、逐个图层手动延长，非常繁琐。点一次按钮即可全部 +30 秒，不够再点一次。

## 方案调研

After Effects ExtendScript 中：

- `CompItem.duration`（Number，读写）：合成总时长，单位秒。
- `Layer.outPoint`（Number，读写）：图层出点，单位秒。
- 预合成层：`layer.source` 指向一个 `CompItem`，可以递归进入。
- 必须同时延长**合成时长**和**图层 outPoint**：只延图层会让 outPoint 超出旧合成时长；只延合成会导致图层在旧 outPoint 处提前消失。

## 实现

新增/修改文件：`src/tools.jsx`、`src/ui.jsx`。

```javascript
function OF_Tools_extendOutTime30s(){
    if(!app.project || !app.project.activeItem) return;
    var comp = app.project.activeItem;
    if(!(comp instanceof CompItem)) return;

    app.beginUndoGroup("Extend OutTime +30s");
    var visited = {};
    extendCompRecursive(comp, visited);
    app.endUndoGroup();

    function extendCompRecursive(c, visited){
        if(!c || !(c instanceof CompItem) || visited[c.id]) return;
        visited[c.id] = true;
        // 先延长合成时长，避免后续图层 outPoint 被旧时长限制
        c.duration += 30;
        for(var i = 1; i <= c.numLayers; i++){
            var layer = c.layer(i);
            if(!layer) continue;
            try { layer.outPoint += 30; } catch(e){}
            if(layer.source && layer.source instanceof CompItem){
                extendCompRecursive(layer.source, visited);
            }
        }
    }
}
```

关键设计点：

- 先 `c.duration += 30`，再处理图层。这样 `layer.outPoint += 30` 后的新值一定落在新的合成时长范围内。
- 递归进入 `layer.source` 预合成，对其内部图层和合成时长做同样处理。
- 用 `visited[c.id]` 防止预合成循环引用导致死循环。
- `try/catch` 兜底，避免某些特殊图层类型报错中断。

## UI 改动

- 按钮 `onClick` 绑定到 `OF_Tools_extendOutTime30s`。

## 待验证

- 打开一个含 PSD 预合成的 10 秒合成，点击 `+30s`。
- 当前合成时长应变为 40 秒，所有图层的 outPoint 都应向后推 30 秒。
- 进入任意嵌套预合成，其内部合成时长和图层 outPoint 也应同步延长。
- 对 10 秒合成连续点击两次，最终时长应为 70 秒。
- 当前活跃项不是合成时，脚本不报错。

## 备注

- 当前硬编码 30 秒。后续如果想自定义秒数，可以改成弹窗输入（`prompt`）或在 UI 上加一个数字输入框。
- 该工具会修改所有图层 outPoint，包括原本被特意裁剪过的图层。如果后续需要只延长“到边界”的图层，可以再做一个更智能的版本。
