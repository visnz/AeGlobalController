# 50% 预览合成批量工具报告

日期：2026-11-02

## 需求 / 目标

在 Tools 分页的 batch 行新增一个按钮，为 Project 面板里**所有选中的合成**，每个单独生成一个 50% 缩放的预览合成，用于渲染一整套选中集合的 50% 大小预览视频。

## 实现摘要

- `src/tools.jsx`：
  - `OF_Tools_makeHalfSizeComps()`：主流程。
    - 取 `OF_Tools_getProjectSelectedComps()` 得到的合成列表。
    - 对每个合成：新建合成（宽高 = 原尺寸 / 2，`Math.round` 取整），`addComp(newName, halfW, halfH, pixelAspect, duration, frameRate)` 保留原合成的像素长宽比、时长、帧率。
    - 命名规则：`原名 + "_50%"`。
    - 新合成放到原合成的 `parentFolder` 下，与原合成同目录。
    - 把原合成作为图层 `newComp.layers.add(src)` 加入，`layer.scale.setValue([50, 50])` 缩放到 50%（内容完整填满减半后的画布）。
    - 全程一个 `app.beginUndoGroup`，用 `OF_Log` 逐个/汇总记录。
    - 生成完成后，先取消原合成（`comps`）的选中，再把刚生成的 50% 合成（`newComps`）逐个 `selected = true`，这样 Project 面板只选中新生成的 50% 合成，用户可直接 `Ctrl+M` 把它们加入渲染队列。
  - `OF_Tools_getProjectSelectedComps()`：遍历 `app.project.items`，取所有 `selected` 的 `CompItem`（排除 `_OF_CacheQueue` 内部数据合成）；若 Project 面板没选中任何合成，回退到 `activeItem`（当前活动合成）。
- `src/ui.jsx`：batch 行（line2）新增按钮 `half`（文本 `50%`），末尾接线 `OF_Tools_makeHalfSizeComps`。
- 已 `bash ./build.sh` 重新生成 `visnlink.jsx`。

## 踩的坑

- `build.sh` 再次因 `core.autocrlf=true` 被签出成 CRLF，`bash ./build.sh` 报 `set: -\r`。本次新增 `.gitattributes`（`*.sh text eol=lf`）根治：`.sh` 文件以后永远以 LF 签出，不再需要每次手动转行尾。

## 待验证

1. AE 里关面板 → 复制根目录 `visnlink.jsx` 到 AE 2024 `ScriptUI Panels` 目录 → 重开面板，batch 行出现 `50%` 按钮。
2. Project 面板选中多个合成，点 `50%`，确认每个合成都生成一个 `原名_50%` 的新合成，尺寸为原尺寸一半，且新合成里的原合成图层 scale 为 50%。
3. 新合成时长、帧率、像素长宽比与原合成一致，且位于原合成所在文件夹。
4. 撤销（Ctrl+Z）能一次性还原全部生成结果。
5. 未选中任何合成时点按钮，Log 面板给出提示、不报错。
6. 生成后 Project 面板里选中的是刚生成的 `_50%` 合成（原合成已取消选中），直接 `Ctrl+M` 能把它们一起加入渲染队列。
