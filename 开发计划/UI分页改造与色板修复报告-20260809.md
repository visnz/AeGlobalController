# UI 分页改造与色板修复报告

日期：2026-08-09

## 需求 / 目标

1. 把主面板最上方改成 `Tools` / `Cache` 两个分页，减少同时摆在眼前的控件数量。
2. Cache Manager 不再弹出独立窗口，而是收进 `Cache` 分页内部。
3. 修复此前加入 Log 面板后色板（`colorGroup`）消失的问题。

## 实现摘要

### 1. `src/ui.jsx`

- 顶层结构改为：
  - `tabRow`：两个分页按钮 `Tools` / `Cache`。
  - `panelContainer`：包含 `toolsPanel` 与 `cachePanel`，通过 `visible` 切换。
  - `logGroup`：保持在最底部，不受影响。
- `toolsPanel` 收纳原来的 `outsideGroup`（集成脚本、工具按钮、Ease、AnchorMove、表达式列表）、`colorGroup`（色板）、`transGroup`（中英查找）。
- `cachePanel` 内置 Cache Manager 所需的模板名输入框、路径显示、`Set`、`Refresh`、`Cache` 按钮和状态文本。
- 所有内部控件路径从 `myPalette.grp.xxx` 更新为 `myPalette.grp.toolsPanel.xxx`。
- 分页切换函数 `switchTab` 会同时修改按钮文本前缀（`●`）并触发 `layout.resize()`。
- Cache 面板里的 ListBox 改为固定高度并加了说明标签，避免空列表时被误认为“一大块空白”。

### 2. `src/tools.jsx`

- 删除原来的 `OF_Tools_openCacheManager()`（独立窗口实现）。
- 新增 `OF_Tools_initCachePanel(panel)`，接收 `ui.jsx` 传入的 `cachePanel` 分组：
  - 初始化时读取已保存的缓存目录并显示。
  - 根据当前选中的合成递归收集依赖树，按深度降序排列。
  - 双击列表项切换勾选状态。
  - `Refresh` 重新收集依赖。
  - `Set` 弹出目录选择框并保存到 `visnlink.cacheFolderPath`。
  - `Cache` 按勾选顺序把渲染任务加入队列（仍不自动渲染），与之前逻辑保持一致。
- 保留原有的依赖收集、深度排序、`_pre` 创建/替换、CineForm 模板套用、MOV 导入等函数。
- 新增 `OF_Tools_getCacheOutputModuleTemplate()` / `OF_Tools_saveCacheOutputModuleTemplate(name)`，从 `visnlink.cacheOutputModuleTemplate` 读取/保存模板名；`OF_Tools_applyCineFormRGBA16` 改为套用该设置名。

### 3. 色板修复

- 在 `colorGroup.line1` 上显式加了 `preferredSize:[200,35]`，避免分组高度被压成 0。
- 色板按钮与 15 个色块仍通过代码动态添加到 `colorGroup.line1`，并调用 `drawColortoPanel(colorPanel)` 上色。

## 已知问题 / 待后续优化

1. **分页切换有 1~2 秒延迟**：当前点击 `Tools` / `Cache` 切换时，ScriptUI 需要重新布局整个面板，耗时约 1~2 秒。暂时不影响使用，后续可以考虑：
   - 把不常用控件做成延迟加载；
   - 减少 `toolsPanel` 内的嵌套层级；
   - 或在切换时只隐藏/显示顶层容器而不是整面板重排。
2. **输出模块模板默认可编辑**：Cache 面板新增 `Template` 输入框，默认 `OF_Cache_CineForm_RGBA16_Q4`，修改后会自动保存到 `visnlink.cacheOutputModuleTemplate`。首次使用前仍需手动创建对应模板（或用 `devtools/create_cache_output_module_template.jsx` 辅助保存）。

## 输出模块模板创建说明

缓存功能需要名为 `OF_Cache_CineForm_RGBA16_Q4` 的输出模块模板。由于 AE 脚本 API 限制，无法一键程序化设置格式和编码器，可按以下步骤手动创建：

1. 在 AE 中新建任意合成，拖到渲染队列（Render Queue）。
2. 点击该合成的 **Output Module**（默认显示为 `Lossless`）。
3. 在弹出的 **Output Module Settings** 中：
   - **Format** 选择 `QuickTime`。
   - 点击 **Format Options**，**Video Codec** 选择 `GoPro CineForm`。
   - **Depth** 选择 `Trillions of Colors+`（即 RGBA 16bit）。
   - **Quality** 设为 `4`。
4. 点击 OK 关闭 Format Options，再点击 OK 关闭 Output Module Settings。
5. 回到渲染队列，展开 Output Module 下拉菜单，选择 **Make Template**。
6. 模板名输入 `OF_Cache_CineForm_RGBA16_Q4`，保存。

保存后，脚本的 Cache 功能即可正常套用该模板。

## 辅助脚本

`devtools/create_cache_output_module_template.jsx` 用于减少手动创建模板的出错概率：

1. 第一次在 AE 里运行：会创建一个临时合成 `Visn_CacheTemplate_Setup` 并加入渲染队列，然后弹窗提示你去设置 QuickTime / GoPro CineForm / RGBA 16bit / Quality 4。
2. 按提示在渲染队列里双击该合成的 Output Module 完成设置。
3. 第二次运行：把当前设置保存为模板 `OF_Cache_CineForm_RGBA16_Q4`，并清理临时合成。

> 如果模板名已改为其它名字，请先在第一阶段把 Output Module 保存为相同名字，或在 Cache 面板的 `Template` 输入框里改成一致的名字。

## 中间踩的坑 / 试错

1. **Cache Manager 的 `Cache Selected` 按钮之前“不存在”**：根本原因是 ScriptUI 资源字符串里某些组末尾带了多余逗号，导致后续控件被静默丢弃。这次重写 `ui.jsx` 的 `cachePanel` 资源字符串时仔细检查了每处逗号，确保没有 trailing comma。
2. **色板消失**：不是因为代码逻辑丢失，而是 `colorGroup.line1` 没有显式高度，在加入 Log 面板后整体布局被压缩。加 `preferredSize` 后恢复可见。
3. **分页切换后布局没刷新**：`visible` 切换后必须再调 `layout.layout(true)` + `layout.resize()`，否则隐藏/显示的面板尺寸不会更新。
4. **独立窗口 vs 内嵌面板**：原本 Cache Manager 是 `new Window(...)`，现在改为初始化传入已有分组，相关引用从 `w.grp.xxx` 全部改成 `panel.xxx`。

## 待验证

1. 在 AE 中打开面板后，默认显示 `Tools` 分页，色板、集成脚本、Ease、AnchorMove、中英查找均正常显示。
2. 点击 `Cache` 分页切换到缓存管理器，能看到当前选中合成的依赖树列表。
3. 双击列表项能切换 `[x]` / `[ ]`。
4. 点击 `Set` 选择缓存目录后，路径文本正确更新。
5. 点击 `Cache` 后弹出确认对话框，确认后渲染队列中按依赖顺序出现对应合成任务。
6. 点击底部 `Log: OFF` 按钮能展开/收起日志面板，且日志正常输出。
